# krisha-tracker

Отслеживает объявления о продаже 2–3-комнатных квартир в Астане на krisha.kz
(цена 25–50 млн ₸, дом 2020 г. и новее) и ведёт таблицу в Google Sheets.
Работает по расписанию в GitHub Actions, свой компьютер включённым держать не нужно.

## Что попадает в таблицу

| Колонка | Пояснение |
|---|---|
| ID, Ссылка | номер и адрес страницы объявления |
| Статус | `Активно` / `Нет в выдаче` / `Удалено (404)` |
| Впервые найдено, Последний раз в выдаче | даты (время Астаны) |
| Цена, Прежняя цена, Дата смены цены, Цена за м² | история изменения цены |
| Комнат, Площадь, Этаж, Этажей в доме | |
| ЖК, Адрес, Район | |
| Год постройки, Тип дома, Новостройка | |
| Лифт | `да` / `нет` / `есть, не работает` / `не указан` / `не проверено` |

**Про лифт.** На krisha.kz нет отдельного поля «лифт», поэтому скрипт ищет упоминание лифта
в тексте объявления (описание и характеристики). `не указан` значит, что продавец ничего не написал:
это не то же самое, что «лифта нет». Для таких случаев используйте колонку «Этажей в доме»
(в многоэтажных новых домах лифт обычно есть).
Страницы объявлений открываются порциями (по умолчанию до 100 за быстрый запуск и до 300 за полный),
поэтому на первых запусках у части строк будет `не проверено` — они дозаполнятся сами.

## Как это работает

- **quick** (каждый час): смотрит первые страницы выдачи (самые свежие объявления), добавляет новые.
- **full** (раз в сутки, 03:00 по Астане): обходит всю выдачу, обновляет цены и помечает
  объявления, которых нет два полных обхода подряд, как `Нет в выдаче`.
- Строки не дублируются: ключ — ID объявления. Свои заметки добавляйте в колонки **правее** колонки U
  и не меняйте порядок и названия наших колонок.

## Настройка

### 1. Доступ к Google Sheets

1. Откройте [Google Cloud Console](https://console.cloud.google.com/), создайте проект.
2. **APIs & Services → Library**: включите **Google Sheets API**.
3. **IAM & Admin → Service Accounts → Create service account** (роль не нужна).
4. Откройте созданный сервисный аккаунт → **Keys → Add key → Create new key → JSON**. Скачается файл.
5. Создайте пустую Google-таблицу и нажмите **Поделиться**: добавьте e-mail сервисного аккаунта
   (вида `...@...iam.gserviceaccount.com`) с правом **Редактор**.
6. Скопируйте ID таблицы из адреса: `https://docs.google.com/spreadsheets/d/<ЭТО_ID>/edit`.

### 2. GitHub

1. Создайте репозиторий и загрузите в него содержимое этой папки.
   Лучше **публичный**: GitHub Actions в публичных репозиториях бесплатны без лимита минут, а секреты не видны.
   В приватном репозитории бесплатно 2000 минут в месяц, при почасовых запусках их может не хватить.
2. **Settings → Secrets and variables → Actions → New repository secret**:
   - `GOOGLE_CREDENTIALS` — **полное содержимое** скачанного JSON-файла;
   - `SPREADSHEET_ID` — ID таблицы.
3. Вкладка **Actions** → *krisha-tracker* → **Run workflow** → режим `full`. Первый запуск соберёт всю выдачу.
   Дальше всё идёт по расписанию.

Файл с ключом (`*.json`) никогда не коммитьте — он уже в `.gitignore`.

## Изменение условий поиска

Все фильтры (комнаты, цена, год, число страниц, лимиты) находятся в `config.py`.
Фильтры дублируются в самом поиске и проверяются в скрипте на каждой карточке.

## Проверка на своём компьютере (без Google Sheets)

```bash
pip install -r requirements.txt
python tracker.py --mode quick --store csv --csv-path listings.csv --max-detail 5
python -m unittest discover -s tests
```

## Если что-то пошло не так

- **Запуск завершился с ошибкой, в логе «не найдено ни одной карточки» или `HTTP 403`.**
  Сайт мог поменять вёрстку или не пускает IP-адреса GitHub. В первом случае скачайте артефакт
  `debug-html` из неудачного запуска: по нему можно поправить `parsers.py`. Во втором случае
  запускайте скрипт на своём компьютере или на небольшом сервере (cron / Планировщик заданий Windows):
  команда та же, переменные `GOOGLE_CREDENTIALS` и `SPREADSHEET_ID` задаются в окружении.
- Не делайте запросы чаще — в скрипте уже стоят паузы 1.5–3 секунды между запросами.
  Используйте данные для личных целей и соблюдайте правила сайта.
